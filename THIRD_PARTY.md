# Third-party and reference scope

C01 executes Python standard-library code and the pinned GitHub Actions in .github/workflows/ci.yml. It includes no third-party native library, generated SDK, copied business implementation or embedded generator template.

The five Markdown files in docs/reference are read-only extracts of project-authored MadB documentation at the recorded commit. Original external citations remain attributed; external sources retain their rights. The snapshot is not a copy of tool private code or an independent semantic authority.

Before adding a native fixture, generator fragment or runtime dependency, record its source, version and license. Public release review is separate from the C01 repository checks.
