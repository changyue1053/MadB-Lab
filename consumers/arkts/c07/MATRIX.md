# Independent minimum matrix (planning IDs, no results)

Every applicable row requires independent evidence. Applicability follows the formally resolved route responsibility table and adopted ADRs; this matrix adds no host-VM destruction requirement. `O` uses ordinary public API; `T` additionally uses the public companion; `B` is build/admission evidence. Four-route applicability is below. Expected values and counts are chosen here from ADR-0013, not calculated by reusing provider rules or reading its self-reported limits.

## Four route applicability

| Route | Common rows | Route evidence and env boundary |
|---|---|---|
| ARKTS-C-NAPI (first) | All | C source compiled as C17, real typed C provider allocation/increment/free; shared C++17 protocol and genuine worker permitted by ADR-0011; platform NAPI adapter. Actual main-env normal close and supported Worker env-exit coverage. |
| ARKTS-CPP-NAPI | All | Real C++17 provider/model/RAII destruction, exceptions contained across C/NAPI boundary; shared protocol is allowed. C++-only HAR closure has an explicit runtime owner. Actual supported Worker exit. |
| ARKTS-RUST-NAPI | All | Real Rust provider/model/drop and actual napi-ohos frontend with locked versions; no implicit unbounded Tokio/global executor. Shared C++17 protocol does not replace Rust domain computation/free. Actual supported Worker exit. |
| KN-ARKTS-NAPI | All applicable normal-runtime semantic rows | Actual CPF + generated KSP/ArkProxy + sole managed owner and genuine work/physical-exit proof. The main-env-only profile must recoverably reject Worker-first registration. Normal whole-runtime close occurs while env remains valid: autonomous admission gate/drain, all sentinel/metadata/class refs cleared, and actual TSFN/finalizer ACK. It does not require destruction of the host VM. Real system-hook/null-env observations are separately labeled and assessed only against the formally resolved profile responsibilities; they cannot be inferred from ordinary close, a manual hook, process kill, Future ACK or another route's Worker run. |

These labels await resolved profile/candidate applicability and official problem/source IDs. CRIT01/03/11/12 remain covered by their actual requirements; no row alone is a certificate. Route-independent expected values do not permit skipping actual execution for any route.

Capacity, allocation failure and transport failure are separate cases. A timeout is never an acceptable terminal winner. Diagnostics are checked only at documented coherent or barrier-stable checkpoints; independently read atomics are not assumed to form an instantaneous snapshot. Correct counter inequalities are as important as final balances, e.g. terminal may be committed while work/join is still outstanding.
