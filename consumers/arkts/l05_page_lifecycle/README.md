# L05 actual page destruction and new presentation instances

This independent Lab consumer composes the frozen ordinary C HAR with an
independently pinned public development delivery of StateObservation and
ArkUIStateModel. It does not rebuild the SDK, import private producer sources,
or modify the existing hide/return consumer.

Three Index instances each own a fresh ArkUIStateModel. UIContext Router
replaceUrl destroys Index and enters Away. Only the real aboutToDisappear
callback requests stop and starts asynchronous close; the application test
owner retains each close Promise. Away waits for the callback and successful
drain before publication or another Index creation. Retained old models are
used as evidence witnesses; this does not claim GC or physical memory reclamation.

A separate ordinary Engine.observeState subscription remains on the same Engine
through all three page lifecycles. Six independently expected publications and
three roundtrips prove page teardown does not stop that observer or close the
shared Engine. Final Subscription/Engine/Runtime close is explicit and separate
from stopping/uninstalling the test bundle.

The oracle checks exact nonce/PID-bound ordered frames and unique actual UI
hierarchy text nodes. Compile, real native consumption, UI lifecycle, public
close confirmation and device cleanup have separate report fields. Host parser
rejection checks are not device evidence.

The original ordinary candidate cannot force an already queued late callback or
native close failure. Publishing after confirmed drain does not prove that
interleaving. Background/rotation, concurrent pages, other routes, Worker env,
physical targets and formal extension distribution remain outside this slice.

Run scripts/test_l05_page_lifecycle.py for host oracle rejection checks. The
explicit target entry is scripts/verify_l05_page_lifecycle.py with frozen
candidate/source hashes and the candidate-bound formal SDK/JBR. It owns only
com.madb.l05lifecycle on the coordinator-assigned target, requires a fresh output
directory, and retains failed outputs. No external package downloads or tool
updates are required. Source and archive identities are captured before/after.
