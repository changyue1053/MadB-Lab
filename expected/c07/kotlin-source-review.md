## What the helper binds

`verify_kotlin_source_review(admitted_candidate)` checks the exact ordinary/test source-reference set against the independently maintained inventory and `madb.lock`; this includes owner code, immutable upstream bases, source pin, patch, test codec derivation, native support, generator/recipe bytes and formal headers. Unknown or rehashed source, patch, generated Kotlin or recipe bytes do not match this inventory merely by changing receipts.

The actual KSP generated text is rehashed and compared with the finite generated-output inventory; its facts, record schema and declaration agree with the Source products. Compile and Link Gradle task names, parser outputs and actual tool identities must agree. Native Compile commands admit exactly the reviewed helper/support/bootstrap unit set and flags, selected observer units and archive members. The existing `kotlin-compile.json` must be a published candidate member, match its accepted Compile output reference, and reproduce the actual KSP declaration and identity. Link must consume the expected archives/bootstrap objects and the recorded Kotlin shared object; normalized linker argv permits only the finite reviewed arguments and existing exact Scrt1 correction. Link output hashes, candidate ELF bytes, admitted HAR native bytes and owner-loader symbol receipts agree.

`bound` is this bounded static condition. It is not runtime success or an independently rebuilt binary. Original source/patch bytes, C++ depfiles and Konan internal source dependencies/temporary objects are not shipped in the examined candidates. These are explicit limits, not newly invented acceptance requirements. The original/derived runtime relation is the fixed reviewed source-pin/base/patch/result relationship; the helper does not replay the producer patch implementation as an oracle.

`verify_kotlin_profile_pair(ordinary, companion)` repeats both static bindings, requires the existing ordinary profile ID plus `-test`, the same approved producer revision and the mechanical common source-reference intersection. Its result identifies both candidate digests and common references. The controller independently validates the ordinary runtime report and all its attachments; this helper never trusts a report's `passed` label.
